NSmithy generates handler interfaces whose methods accept modeled inputs and
return modeled outputs. You implement the operations; the runtime handles
serialization, dispatch, and modeled errors.

## Reference the protocol package

Reference `NSmithy.Server.AspNetCore` and the package for each protocol your
server generates. The host is protocol-agnostic and does not bring in protocol
or codec packages itself; each protocol package brings its required codecs.
The `nsmithy-server` template adds the matching reference automatically.

| Service protocol | Package to add alongside `NSmithy.Server.AspNetCore` |
| --- | --- |
| `restJson1` or `simpleRestJson` | `NSmithy.Protocols.RestJson` |
| `rpcv2Cbor` | `NSmithy.Protocols.RpcV2Cbor` |
| `grpc` | `NSmithy.Protocols.Grpc` |

When upgrading an existing REST/JSON or gRPC server, add the corresponding
protocol package explicitly, using the same NSmithy version as the host.

## Implement an operation

For a `Library` service with a `GetBook` operation, modeled as in
[Modeling contracts](/smithy-dotnet/concepts/modeling/), implement the generated
service interface:

<Tabs syncKey="lang">
  <TabItem label="C#">
    ```csharp
    internal sealed class LibraryHandler : ILibraryServiceHandler
    {
        public Task<GetBookOutput> GetBookAsync(
            GetBookInput input, CancellationToken ct = default)
        {
            if (input.Id != "1")
                throw new BookNotFound("Book not found.");

            return Task.FromResult(new GetBookOutput(input.Id, "The Odyssey"));
        }
    }
    ```
  </TabItem>
  <TabItem label="F#">
    ```fsharp
    type LibraryHandler() =
        interface ILibraryServiceHandler with
            member _.GetBookAsync(input, _) =
                if input.Id = "1" then
                    Task.FromResult(Ok { Id = input.Id; Title = "The Odyssey" })
                else
                    Task.FromResult(Error(GetBookError.BookNotFound(BookNotFound("Book not found."))))
    ```
  </TabItem>
</Tabs>

Return an output for success. For a modeled failure, throw a generated error in
C#; in F#, return it as the `Error` case of the operation's error union.
The selected protocol determines the response encoding and status.

## Register and map

<Tabs syncKey="lang">
  <TabItem label="C#">
    ```csharp title="Program.cs"
    using Example.Library;

    var builder = WebApplication.CreateBuilder(args);
    builder.Services.AddLibraryServiceHandler<LibraryHandler>();

    var app = builder.Build();
    app.MapLibraryService();
    app.Run();
    ```
  </TabItem>
  <TabItem label="F#">
    ```fsharp title="Program.fs"
    open Example.Library
    open Microsoft.AspNetCore.Builder
    open Microsoft.Extensions.DependencyInjection

    [<EntryPoint>]
    let main args =
        let builder = WebApplication.CreateBuilder(args)
        builder.Services.AddLibraryServiceHandler<LibraryHandler>() |> ignore

        let app = builder.Build()
        app.MapLibraryService() |> ignore
        app.Run()
        0
    ```
  </TabItem>
</Tabs>

`Add{Service}Handler<THandler>` registers the implementation, service metadata,
and default server runtime. `Map{Service}` maps the first declared supported
server protocol. To select several, see
[Hosting multiple protocols](/smithy-dotnet/servers/hosting/).

## Separate operation handlers

The service interface inherits one interface per operation:

<Tabs syncKey="lang">
  <TabItem label="C#">
    ```csharp
    public interface IGetBookHandler
    {
        Task<GetBookOutput> GetBookAsync(GetBookInput input, CancellationToken ct = default);
    }

    public interface ILibraryServiceHandler : IGetBookHandler { }
    ```
  </TabItem>
  <TabItem label="F#">
    ```fsharp
    type IGetBookHandler =
        abstract GetBookAsync:
            input: GetBookInput * cancellationToken: CancellationToken -> Task<GetBookOutput>

    type ILibraryServiceHandler =
        inherit IGetBookHandler
    ```
  </TabItem>
</Tabs>

Endpoints resolve the per-operation interfaces. To split a service across
implementations, register each one instead of using the aggregate helper:

<Tabs syncKey="lang">
  <TabItem label="C#">
    ```csharp
    builder.Services.AddLibraryService();
    builder.Services.AddScoped<IGetBookHandler, GetBookHandler>();
    ```
  </TabItem>
  <TabItem label="F#">
    ```fsharp
    builder.Services.AddLibraryService() |> ignore
    builder.Services.AddScoped<IGetBookHandler, GetBookHandler>() |> ignore
    ```
  </TabItem>
</Tabs>

Register a handler for every mapped operation. `GetBookHandler` implements
`IGetBookHandler` with the same method shown above.

error responses, and streaming limits.
